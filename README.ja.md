# 音声入力 (VoiceInput)

[English](README.md) · [繁體中文](README.zh-Hant.md) · **日本語**

**Mac と Windows 用のオフライン音声入力** —— ホットキーを押して話すと、テキストがどのアプリでもカーソル位置に直接入力されます。端末内で動く Whisper、**60 以上の言語**に対応、**完全オフライン** —— 音声が端末から出ることはありません。**中国語・日本語・韓国語**の精度はこの種のツールでは群を抜きます。

このリポジトリは**公開リリース**を配布します。

## ダウンロード

最新版を **[Releases](../../releases)** から入手してください。

| プラットフォーム | ファイル | 備考 |
|---|---|---|
| macOS | `VoiceInput-x.y.zip` | 初回起動時にモデルをダウンロード（約 574MB） |
| Windows | `VoiceInput-x.y.z-setup.exe` | モデル同梱。インストール後すぐオフラインで使えます |

## インストール — macOS

1. ダウンロードして解凍 → **VoiceInput.app** を「アプリケーション」フォルダへドラッグ
2. 起動（Apple Developer ID 署名 + 公証済みのため、Gatekeeper の警告は出ません）
3. 初回ガイドに従って、認識モデルのダウンロードと「マイク」「アクセシビリティ」を許可
4. どのアプリでもホットキーを押して話すと、カーソル位置にテキストが挿入されます

## インストール — Windows

1. `VoiceInput-x.y.z-setup.exe` を実行（管理者権限は不要）
2. 通知領域に常駐します。**左 Ctrl** を軽く押すと録音開始、もう一度押すと終了
3. トレイアイコンを右クリックすると、設定・ファイル文字起こし・ライセンスを開けます

他に用意するものはありません。認識モデルも必要なライブラリもすべて同梱しています。
GPU 高速化には **Vulkan** を使います。Vulkan の実行環境はグラフィックドライバーに含まれるため、
NVIDIA・AMD・Intel のいずれも同じビルドで動作します。Vulkan が使えない環境では CPU で動作し、
動作はしますが大幅に遅くなります。

> Windows 版はまだ**コード署名をしていない**ため、初回起動時に SmartScreen の警告が出ます。
> 「詳細情報 → 実行」を選んでください。署名は今後のリリースで対応予定です。

## 動作環境

| | macOS | Windows |
|---|---|---|
| OS | macOS 14 以降 | Windows 10 以降（64 ビット） |
| 推奨 | Apple Silicon（M シリーズ） | ドライバーが最新の GPU |
| 空き容量 | モデル用に約 600MB | 約 700MB |

## 特長

- 端末内 Whisper（large-v3-turbo）、多言語で高精度
- 完全オフライン・プライバシー保護
- どのアプリにも入力 · CJK 組版の最適化（和欧文の空白・句読点・簡繁）
- 中国語の句読点を自動で復元
- 単語登録 · 修正学習 · 二言語のワンタップ切替
- 音声・動画ファイルをテキストまたは SRT 字幕に文字起こし
- 表示言語：繁体字中国語 / 簡体字中国語 / 日本語 / 英語

ライセンスは **Mac と Windows で共通**です（台数は合算してカウントされます）。
